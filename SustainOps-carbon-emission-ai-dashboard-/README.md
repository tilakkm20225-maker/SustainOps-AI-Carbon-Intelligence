## 🌿 SustainOps: AI-Powered Carbon Emission Management

SustainOps is an intelligent analytics dashboard built to monitor, analyze, and forecast carbon emissions based on energy production
and consumption data. This project bridges the gap between Environmental Sustainability and Machine Learning, providing actionable
insights to help organizations move toward Net-Zero goals.

### 🚀 Key Features

Real-Time Monitoring: Interactive dashboard visualizing energy production across various sources (Solar, Wind, Coal, Nuclear, etc.) and calculating the corresponding carbon footprint.

Predictive Analytics: Implements Facebook Prophet for time-series forecasting, allowing users to anticipate emission trends over 30 to 365-day horizons.

What-If Scenario Simulation: A dynamic simulation tool that allows users to adjust energy source dependencies and immediately visualize the potential reduction in carbon output.

Geospatial Insights: Integrated Pydeck 3D maps to track emissions across global facilities (mock data implementation).

Custom UI/UX: A professional, split-screen authenticated interface with custom branding.

### 🛠️ Tech Stack

Language: Python

Framework: Streamlit

Time-Series Modeling: Facebook Prophet

Data Visualization: Plotly, Pydeck

Data Processing: Pandas, NumPy

### 📊 Dataset

The project utilizes the Hourly Electricity Consumption and Production dataset, which tracks diverse energy sources including:
Renewables: Wind, Solar, Hydroelectric, Biomass

Non-Renewables: Coal, Oil, and Gas

Low-Carbon: Nuclear
Carbon emissions are calculated using standardized emission factors (tons of $CO\_2$ per MWh) for each specific energy source.
